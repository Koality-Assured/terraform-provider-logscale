# Security Policy

## Supported Versions

Only the latest release of this Terraform provider is currently supported with security updates.

## Reporting a Vulnerability

Please report vulnerabilities using GitHub's private vulnerability reporting feature on this repository.

Navigate to the **Security** tab, select **Advisories**, and click **Report a vulnerability**. This allows you to confidentially report the issue to the maintainers.

Please provide as much information as possible, including:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The provider version you are using.

We will review the report and coordinate with you on the fix and disclosure. Please do not open public issues for security vulnerabilities.
